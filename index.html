¿Qué es CSS?

CSS (Cascading Style Sheets) o Hojas de Estilo en Cascada es el lenguaje de diseño gráfico utilizado para definir y crear la presentación de un documento estructurado escrito en HTML o XML, controlando colores, fuentes, espaciados y el diseño responsivo de las páginas web.

¿Qué aprenderé en este curso?

Aprenderás desde los fundamentos del lenguaje y el modelo de caja hasta técnicas avanzadas como Flexbox, CSS Grid, variables personalizadas (custom properties), control de posiciones, animaciones fluidas y preprocesadores como Sass.

¿Qué es CSS GRID?

CSS Grid Layout es un sistema de diseño bidimensional para CSS que permite dividir una página web en áreas o regiones principales, facilitando la creación de estructuras complejas de filas y columnas de forma limpia y eficiente.
